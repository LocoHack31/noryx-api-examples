# Noryx API Examples

Public integration examples and non-sensitive API usage patterns for the Noryx Finance platform.

This repository is intended for educational and integration reference purposes.

## Scope

Examples may demonstrate concepts such as:

- authentication patterns
- market-data requests
- signal-response structures
- status checks
- analytics queries
- exchange-connectivity workflows

All examples use non-sensitive placeholder data.

## Important

This repository does not contain:

- production API keys
- private endpoints
- internal service URLs
- proprietary trading logic
- strategy parameters
- database credentials
- webhook secrets
- user data
